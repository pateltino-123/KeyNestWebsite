# KeyNest Realty Property Management Frontend

Web and mobile frontend application for **KeyNest Realty Property Management**, built with **Expo**, **React Native for Web**, and **Expo Router**.

Operating under the brokerage of **Fair Deal Realty Inc.** (TREC Licensed).

---

## Quick Start

\`\`\`bash
# Install dependencies
bun install

# Start local web development server
bun run web
\`\`\`

---

## Production Build

\`\`\`bash
# Build static web deployment bundle
npx expo export -p web
\`\`\`

All web bundle files are built to \`dist/\` and deployed to Netlify automatically.
